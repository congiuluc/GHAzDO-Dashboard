# Security policy

## Supported versions

Security fixes are provided in the latest released version. Use the latest
extension and backend packages together; older releases are not maintained
separately.

## Reporting a vulnerability

Report suspected vulnerabilities privately through
[GitHub's vulnerability reporting form](https://github.com/congiuluc/GHAzDO-Dashboard/security/advisories/new).
Do not disclose vulnerabilities, credentials, secret values, or customer data
in public issues, discussions, or pull requests.

Include affected versions, reproduction steps, the expected security impact,
and a minimal example with synthetic or redacted data. If a credential was
exposed, revoke or rotate it immediately rather than waiting for a fix.

The maintainer will coordinate investigation and disclosure through the private
report. Response and remediation times depend on the severity and available
maintainer capacity; no response-time guarantee is provided.
